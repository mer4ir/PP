## Анализ результатов

### Ключевые выводы

1. **MPI обеспечивает хорошее ускорение:**
   - Максимальное ускорение: **8.68x** (2000×2000, 8 процессов)
   - Для 2-4 процессов ускорение близко к линейному (1.93x-3.89x)

2. **Эффективность:**
   - 2 процесса: 96-98% (отлично)
   - 4 процесса: 93-97% (хорошо)
   - 8 процессов: 77-108% (хорошо)

3. **Производительность:**
   - Максимальная: **3.03 GFLOPS** (2000×2000, 8 процессов)
   - 1 процесс: ~0.35 GFLOPS

### Сравнение с законом Амдала

Теоретическое ускорение для 8 процессов при последовательной доле 5%:

S = 1 / (0.05 + 0.95/8) = 5.93x

Фактическое ускорение: **6.21x - 8.68x**

**Вывод:** Фактическое ускорение превышает теоретическое.
